🏗️ Infrastruktur Docker + Terraform (IaC)

Masalah:

Provisioning container secara manual (via `docker run`) rentan terhadap human error, tidak konsisten antar lingkungan, dan sulit di-replicate.

Cara Kerja:

Mengimplementasikan Infrastructure as Code (IaC) menggunakan Terraform. Mendefinisikan Nginx container, isolated Docker network, dan port mapping secara deklaratif dalam file konfigurasi.

Hasil / Dampak:

Infrastruktur dapat di-deploy atau di-destroy sepenuhnya hanya dengan 1 perintah (`terraform apply`), menjamin konsistensi lingkungan development dan memudahkan troubleshooting.

📊 Monitoring Stack (Prometheus & Grafana)

Masalah:

Kesulitan memantau kesehatan sistem (CPU, RAM, Disk) secara real-time tanpa alat visualisasi yang terpusat dan mudah dibaca.

Cara Kerja:

Menyusun stack monitoring menggunakan Docker Compose yang mengintegrasikan Node Exporter (pengumpul metrik), Prometheus (penyimpanan metrik tiap 15 detik), dan Grafana (visualisasi dashboard).

Hasil / Dampak:

Dashboard pemantauan real-time yang dapat dijalankan dengan satu perintah (`docker compose up`), memudahkan deteksi dini anomali sistem tanpa konfigurasi manual yang rumit.

Docker ComposePrometheusGrafanaNode Exporter
